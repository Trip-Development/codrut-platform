# API Contract

Codrut exposes its FastAPI contract at `/api/openapi.json` and stores the
tracked snapshot at:

```text
docs/api/openapi.json
```

## Export

Use the container-backed command:

```sh
just export-openapi
```

Check whether the tracked snapshot is current without rewriting it:

```sh
just openapi-snapshot-check
```

The export command renders the schema from `codrut.main:create_app` and writes
deterministic JSON with sorted keys.

## Generated Frontend Types

Frontend schema types are generated at:

```text
frontend/src/api/generated/schema.d.ts
```

The checked-in facade is:

```text
frontend/src/api/generated/client.ts
```

Generated OpenAPI paths include the backend `/api` prefix. The facade strips
that prefix before joining the path with `frontend/src/api/runtime.ts`, because
the runtime base URL already resolves to `/api` in the browser and to the
internal backend API base on the server.

## Drift Checks

For contract changes, run the container-backed export and generation commands:

```sh
just export-openapi
just generate-client
```

Then inspect the diff for the tracked contract artifacts:

```sh
git diff -- docs/api/openapi.json frontend/src/api/generated/schema.d.ts
```

Expected drift is limited to intentional API shape changes, stable operation ID
changes, or generated type updates caused by backend schema changes in the same
PR. Unexpected drift means the backend schema, operation IDs, or generated
frontend types changed without an explicit contract reason.

Use this check to fail fast without rewriting tracked files:

```sh
just openapi-snapshot-check
```

Use this check to validate that frontend generation can still parse the live
container-network schema without touching the tracked generated file:

```sh
just openapi-check
```

## Operation IDs

Operation IDs are generated by
`codrut.api.openapi.generate_stable_operation_id`.

The convention intentionally preserves the existing FastAPI-style shape:

```text
<route_function_name><normalized_api_path>_<http_method>
```

Example:

```text
login_api_auth_login_post
```

Do not rename route functions casually. Route function names are now part of the
generated-client contract even when the URL and method stay unchanged.
